# About me

I am **Kaleb AKAKPO**, a Software Engineering student interested in **software development, Data Science, and Machine Learning**.

My background combines software engineering with data-driven problem solving.

On the software engineering side, I enjoy building structured and maintainable applications using **Java and Spring Boot**, working with REST APIs, databases, authentication, security, and application architecture.

Alongside software development, I explore **Data Science and Machine Learning** using Python, working with datasets to perform data analysis, build predictive models, and extract useful insights.

I enjoy understanding both sides of a technical problem: **how to build the software and how to use data to make it smarter.**

### *Managing academic schedules and student attendance in one platform*
