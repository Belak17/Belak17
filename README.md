# About me

I am **Kaleb AKAKPO**, a Software Engineering student interested in both **software development** and **data-driven problem solving**.

My background is mainly built around two complementary areas:

- **Software Engineering** — building structured and maintainable applications with Java, Spring Boot, REST APIs, databases, and application security.
- **Data Science & Machine Learning** — exploring data analysis, predictive modeling, and machine learning using Python and its data science ecosystem.

I enjoy working on projects where software engineering and data can come together to solve real-world problems.

### What I enjoy working on

- Backend development with Java and Spring Boot
- REST API design and application architecture
- Relational databases and data modeling
- Data analysis and visualization
- Machine Learning and predictive modeling
- Turning datasets into useful insights
- Building reliable and maintainable software
