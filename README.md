## About Me

Hi! I'm **Kaleb AKAKPO**, a Software Engineering student currently pursuing a Bachelor's degree in Software Engineering and Information Systems at the University of Gabès, Tunisia.

I'm interested in building reliable software applications and exploring how data and machine learning can solve practical problems.

My main focus is backend development with **Java, Spring Boot, and PostgreSQL**. I also work with Python for data analysis and machine learning projects.

Through academic projects and internships, I've gained practical experience in web application development, REST APIs, database integration, authentication, and application security.

### What I work with

- **Backend Development:** Java, Spring Boot, Spring Security, Hibernate, REST APIs
- **Databases:** PostgreSQL, Oracle, SQL
- **Frontend:** HTML, CSS, JavaScript, Thymeleaf
- **Data Science:** Python, Pandas, NumPy, Scikit-learn
- **Tools:** Git, GitHub, Maven, Postman, JUnit

I'm interested in junior software development opportunities, paid internships, and technical projects where I can contribute, learn, and grow.
